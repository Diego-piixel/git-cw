Etiqueta Para que sirve Ejemplo mínimo
table Crea una tabla 

<table>
    <tr>
        <th>Etiqueta </th>
        <th>Uso </th>
    </tr> 
<table>
code Coloca un pedazo de código en el html 

<pre><code>
    #include &lt; stdio.h &gt;
    main()
    {
        printf("Hola mundo");
        return0;
    }
</code></pre>
pre Coloca el texto exactamente como lo escribes en el html 
<pre>
        <p>   Holaa   soy     diego </p>
</pre>
ul Crea una lista desordenada 

<ul>
    <li> Tacos </li>

</ul>

<lo>
    <li> 8:00 </li>
