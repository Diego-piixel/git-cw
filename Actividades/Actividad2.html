Explicando un codigo de c en html.

Código.



  #include <stdio.h>


  int main() {
    int edad;
    printf("¿Cuántos años tienes? ");
    scanf("%d", &edad);


    if (edad >= 18) {
        printf("Eres mayor de edad.\n");
    } else {
        printf("Eres menor de edad.\n");
    }


    return 0;
  }

Explicación.

#include <stdio.h>

Agrega la libreria stdio.h

int main()

Define la función principal del programa.

int edad;

Declara una variable de tipo entera llamada edad.

printf("¿Cuántos años tienes? ");

Manda a pantalla el mensaje "¿Cuántos años tienes? ".

scanf("%d", &edad);

Pide al usuario introducir un valor que se almacenará en la variable edad.
El & indica la dirección de memoria de edad, necesaria para que scanf pueda modificarla.


if (edad >= 18) {
    printf("Eres mayor de edad.\n");
} else {
    printf("Eres menor de edad.\n");
}

Si edad es igual o mayor a 18 madará a pantalla el mensaje "Eres mayor de edad"
y se realizará un cambio de linea, en caso contrario, se mostrará el mensaje
"Eres menor de edad" y se realizará un cambio de linea.

return 0;

Finaliza la función main.
